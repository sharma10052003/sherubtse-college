# /assets/images

`sherubtse-logo.svg` in this folder is a **placeholder crest** — swap it
for the College's real logo before going live (see `docs/BRANDING.md`).

Recommended files to add:

| File | Purpose | Recommended format |
|---|---|---|
| `sherubtse-logo.svg` | Header + footer crest | SVG (scales crisply at any size) |
| `favicon.ico` | Browser tab icon | 32×32 / 48×48 multi-size .ico |
| `favicon-192.png`, `favicon-512.png` | PWA / mobile home-screen icons | PNG |
| `og-image.jpg` | Social share preview (optional, used outside this component) | JPG, 1200×630 |

Keep the logo file under ~30 KB (SVG) so it doesn't work against the
Lighthouse performance budget described in `docs/PERFORMANCE.md`.
